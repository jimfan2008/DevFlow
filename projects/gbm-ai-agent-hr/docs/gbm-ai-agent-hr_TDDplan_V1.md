# GBM AI Agent HR TDD Plan V1

## 1. 概述

本文档定义 GBM AI Agent HR 项目的 TDD 测试驱动开发计划。

## 2. 测试模块

### 2.1 告警通知测试（test_tdd_0040）

- **TDD-001**: 严重级别告警通知范围验证
- **TDD-002**: 非严重级别告警仅通知项目负责人
- **TDD-003**: 告警通知 SLA（≤30 秒）验证
- **TDD-004**: 边界场景（空字典、None level）
- **TDD-005**: 多次告警累积验证

### 2.2 主持人权限测试

- **TDD-006**: 移除成员权限拒绝验证
- **TDD-007**: 解散群组权限拒绝验证
- **TDD-008**: 禁言操作正常执行验证
- **TDD-009**: 公告操作验证
- **TDD-010**: 主持人互操作验证

## 3. 测试执行

```bash
pytest tests/test_cases/ -v
```

## 4. 验收标准

- 所有测试用例通过率 100%
- 无 flaky tests
- 测试运行时间 < 30 秒
