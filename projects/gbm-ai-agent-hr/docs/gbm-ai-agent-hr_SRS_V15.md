# GBM AI Agent HR SRS V15

## 1. 引言

本文档定义 GBM AI Agent HR 项目的软件需求规格（第 15 版）。

## 2. 功能需求

### 2.1 告警通知系统

- **FR-001**: 严重级别告警应通知系统管理员和项目负责人
- **FR-002**: 非严重级别告警仅通知项目负责人
- **FR-003**: 告警通知应在 ≤30 秒内送达

### 2.2 主持人权限系统

- **FR-006**: 主持人可禁言普通成员
- **FR-007**: 主持人可发布公告
- **FR-008**: 主持人可管理会议
- **FR-009**: 主持人不可移除成员
- **FR-010**: 主持人不可解散群组
- **FR-011**: 主持人不可操作其他主持人

### 2.3 HR 流程

- **FR-012**: 支持员工入职流程自动化
- **FR-013**: 支持离职流程自动化
- **FR-014**: 支持请假审批流程

## 3. 非功能需求

- **NFR-001**: 告警处理延迟不超过 30 秒（P99）
- **NFR-002**: 所有操作需审计日志
- **NFR-003**: RBAC 权限控制

## 4. 约束

- 运行环境：Python 3.11+, FastAPI
- 测试框架：pytest + pytest-asyncio
