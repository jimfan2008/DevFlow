## 1. 引言

### 1.1 编写目的

本文档旨在定义 GBM AI Agent HR 智能人力管理系统的完整需求规格，作为系统设计、开发、测试和验收的依据。

### 1.2 项目范围

本系统覆盖企业人力资源管理的核心业务环节，包括：招聘管理、入职办理、培训管理、考勤管理、薪资管理、绩效考核、外务专员管理（工伤与住房公积金）、离职管理等全流程。

系统采用 AI 原生设计理念，以 AI 智能体为核心驱动，替代人工完成重复性、规则化、数据密集型的人力资源操作，实现 HR 工作的全面自动化。

### 1.3 术语定义

| 术语 | 定义 |
|------|------|
| AI Agent | 具有自主决策和执行能力的 AI 智能体，可独立完成特定业务流程 |
| AI 原生系统 | 以 AI 能力为架构核心设计的软件系统，而非在现有系统上叠加 AI 功能 |
| AIOCR | 基于 AI 的光学字符识别技术，用于证件、文档信息提取 |
| 扫码签到 | 通过扫描唯一生成的二维码完成身份验证和签到确认（本文档统一使用"扫码签到"一词） |
| 简历库 | 企业存储和管理候选人简历信息的数字化档案库 |
| 人事档案 | 员工从入职到离职全过程的资料集合 |
| 特种工 | 需要持有特种作业操作证的岗位人员 |
| 体系审核 | 企业内部管理体系（如 ISO 体系）的外部审核（本文档统一使用"体系审核"一词） |
| 前程无忧/中国人才热线 | 企业使用的招聘平台（本文档统一使用"前程无忧"和"中国人才热线"） |
| 工伤备案 | 向社保机构申报工伤事故的资料准备和提交流程 |
| 住房公积金 | 员工住房储蓄制度，需按月缴纳 |
| 上岗证 | 员工完成指定培训后获得的岗位任职资格证明 |
| 关键环节 | 指需要人工审批确认的业务节点，具体包括：离职审批、薪资核算复核、工伤理赔最终确认、待定简历人工审核、主观题评分（详见2.2节） |

## 2. 项目概述

### 2.1 产品背景

企业当前人力资源管理存在以下痛点：

1. 简历筛选工作量大，人工筛选效率低，容易遗漏合适候选人
2. 入职流程繁琐，资料收集、证件录入、协议签署环节多，耗时长
3. 培训管理缺乏自动化工具，签到、考试评分、资料归集依赖人工操作
4. 考勤统计和薪资核算需要大量手工计算，容易出错
5. 外务专员工作（工伤处理、公积金管理）流程复杂，资料整理耗时
6. 绩效考核数据收集分散，汇总整理工作量大
7. 体系审核时，培训资料归集工作集中且繁琐

基于以上痛点，企业决定采用 AI 原生系统设计理念，构建一套 AI Agent 驱动的 HR 智能管理系统，实现人力资源全流程自动化。

### 2.2 AI 原生系统设计原则

本系统遵循以下 AI 原生设计原则：

1. **AI 驱动优先**：业务流程以 AI Agent 自动执行为默认模式，人工仅在以下关键环节介入：离职审批、薪资核算异常复核、工伤理赔最终确认、待定简历人工审核、主观题评分
2. **端到端自动化**：从触发到完成，整个业务流程由 AI 串联执行，减少人工接力环节
3. **数据自学习**：系统通过积累历史数据持续优化匹配规则、评分模型和决策逻辑
4. **智能异常处理**：AI 自动识别以下异常情况并标记：(a)薪资核算结果与上月波动超过20%；(b)考勤数据缺失率超过5%；(c)证件OCR识别置信度低于90%；(d)简历匹配评分在合格线±10分范围内；(e)工伤资料不完整。AI 异常识别准确率目标 ≥ 95%（以人工复核结果为基准）
5. **多模态交互**：支持扫码、OCR 识别、人脸比对、电子签名等多种自然交互方式
6. **归档自动化**：所有业务数据自动生成标准档案，无需人工整理归档

### 2.3 用户角色

| 角色 | 描述 | 主要职责 |
|------|------|----------|
| 系统管理员 | IT 管理人员 | 系统配置、权限管理、数据备份 |
| 人事专员 | HR 操作人员 | 监督 AI Agent 执行、处理异常、审批确认 |
| 部门主管 | 各部门负责人 | 面试结果确认、离职审批、绩效考核确认 |
| 新员工 | 即将入职员工 | 扫码登录、上传证件、签署协议、参加考试 |
| 在职员工 | 正式员工 | 培训签到、考试、绩效考核提交、查看工资条 |
| 外务专员 | 外部事务处理人员 | 工伤申报、公积金管理 |
| 体系审核员 | 内/外部审核人员 | 查看和导出培训、人事相关资料 |

### 2.4 业务目标

#### 2.4.1 核心目标

- 实现 HR 日常工作 90% 以上由 AI Agent 自动完成
- 简历筛选效率提升 10 倍以上
- 入职办理时间从 1-2 天缩短至 1-2 小时
- 薪资核算实现全自动，零人工计算
- 培训管理全流程自动化
- 外务专员事务处理效率提升 80%
- 体系审核资料准备时间从数天缩短至即时完成

#### 2.4.2 分阶段目标

**第一期（核心高频刚需流程）**：
- 招聘端：简历自动筛选、组卷、评分、证件识别、人脸采集
- 考勤薪资端：考勤统计、薪资核算、工资条生成
- 培训端：扫码签到、试卷阅卷
- 绩效端：考核表单收集汇总

**第二期（规则化事务）**：
- 入职资料自动生成档案
- 电子协议核验
- 离职表单自动生成
- 教材转视频
- 培训计划智能整理
- 工伤资料归集
- 公积金补缴计算
- 纸质回执电子化

**第三期（优化增效）**：
- 简历库智能管理
- 特种工智能管理
- 体系审核资料一键归集
- 试用期资料自动汇总
- 各类证明智能填充
- 费用单据智能整理

## 3. 功能需求

### 3.1 招聘管理

#### 3.1.1 人力需求发布

**功能描述**：

支持将招聘信息发布至前程无忧和中国人才热线等招聘平台。

**输入**：
- 岗位名称
- 岗位职责描述
- 任职要求（学历、经验、技能、年龄范围、证书要求等）
- 薪资范围
- 招聘人数
- 发布日期

**处理规则**：
1. 系统维护招聘平台账号信息和接口
2. 根据岗位模板自动生成招聘广告文案
3. 支持手动编辑招聘文案
4. 一键推送至已配置的招聘平台

**输出**：
- 招聘广告发布成功/失败状态
- 各平台发布链接

#### 3.1.2 多平台简历自动筛选与分类归档

**功能描述**：

AI 自动抓取前程无忧/中国人才热线等平台的投递简历，按岗位要求智能匹配打分，自动筛选并分类归档。

**输入**：
- 岗位要求条件（学历、经验、技能、年龄、证书等）
- 各招聘平台待筛选简历数据

**处理规则**：

1. **简历抓取**：
   - AI Agent 定时抓取各招聘平台的新简历投递数据
   - 支持手动触发抓取
   - 自动去重，避免重复简历

2. **智能匹配评分**：
   - AI 解析岗位要求，建立匹配维度权重模型
   - 对每份简历进行多维度评分：
     - 学历匹配度（权重 20%）：按学历等级完全匹配得满分，低一级得60%，低两级及以上得0分
     - 工作经验匹配度（权重 25%）：经验年限满足要求得满分，每差1年扣5分，扣完为止
     - 技能匹配度（权重 20%）：按技能关键词命中率计算，命中全部得满分，按线性比例扣分
     - 年龄匹配度（权重 10%）：在要求年龄范围内得满分，超出范围得0分
     - 证书匹配度（权重 15%）：持有要求证书得满分，缺失得0分
     - 综合匹配度（权重 10%，AI 语义分析）：AI 对简历全文与岗位描述进行语义相似度计算，输出 0-100 分的语义匹配得分；验收基准为：对同一份简历重复评分3次，3次得分标准差不超过5分；对已知合格简历（人事人工确认合格）的语义匹配得分不低于70分
   - 总分 0-100 分（各维度加权求和）
   - 可配置合格分数线（默认 60 分）

3. **自动分类**：
   - 合格简历（分数 > 合格线 + 10 分）：自动下载并导入简历库
   - 待定简历（分数在 合格线 - 10 分 至 合格线 + 10 分 范围内，即 [合格线-10, 合格线+10]）：标记为待定，推送人事人工审核
   - 不合格简历（分数 < 合格线 - 10 分）：自动标记为淘汰，保留记录

4. **自动归档**：
   - 筛选完成后自动下载简历
   - 分类导入企业简历库
   - 同步打上岗位标签、匹配度标签
   - 建立简历电子档案

**输出**：
- 筛选报告（总投递数、合格数、淘汰数、待定数）
- 每份简历的匹配度评分和详细评分明细
- 简历自动归档至简历库
- 合格简历列表推送至人事

#### 3.1.3 面试试卷自动组卷与二维码生成

**功能描述**：

根据面试/转岗/试用期考核岗位，AI 从题库自动抽取试题组卷，一对一生成唯一考试二维码。

**输入**：
- 岗位名称或类型
- 考试类型（面试/转岗/试用期考核）
- 考生信息（姓名、身份证号、应聘岗位等）
- 组卷规则（题型比例、难度分布、题目数量等）

**处理规则**：

1. **题库管理**：
   - 系统维护岗位题库，支持按岗位、题型、难度分类
   - 支持批量导入题目
   - 支持题目增删改查

2. **自动组卷**：
   - AI 根据岗位和考试类型从题库自动抽取试题
   - 组卷规则量化定义如下：
     - 题型分布：单选题占 40%±5%，多选题占 30%±5%，判断题占 30%±5%
     - 难度分布：简单题（1-3分）占 40%±5%，中等题（4-6分）占 40%±5%，困难题（7-10分）占 20%±5%
     - 题目数量：每套试卷不少于 30 题，不多于 50 题
   - 同一岗位同一场次考试中，任意两套试卷重复题目不超过 30%
   - 支持不同考生生成不同试卷（题目随机抽取）

3. **二维码生成**：
   - 为每位考生生成唯一考试二维码
   - 二维码绑定考生信息与对应试卷
   - 二维码关联档案台账
   - 支持打印二维码或电子展示

**输出**：
- 生成的试卷内容
- 唯一二维码（可打印或电子展示）
- 考生-试卷-二维码关联记录

#### 3.1.4 面试答题自动评分

**功能描述**：

招聘环节的客观题由 AI 实时阅卷评分，生成评分明细，自动汇总考核成绩并推送结果。本功能仅处理招聘面试场景的客观题自动评分，不涉及入职培训考试（入职培训考试功能见 3.5.1 节）。

**输入**：
- 考生二维码（扫码登录）
- 考生答题数据（仅客观题：单选、多选、判断题）

**处理规则**：

1. **扫码登录**：
   - 面试人员扫描个人二维码进行身份验证
   - 系统验证身份后加载对应试卷

2. **答题过程**：
   - 考生在线作答客观题（单选、多选、判断）
   - 系统记录答题时间
   - 客观题自动提交

3. **自动评分**：
   - 客观题由 AI 实时阅卷评分，评分规则为：单选题答对得满分、答错得0分；多选题全部选对得满分、部分选对得50%、答错得0分；判断题答对得满分、答错得0分
   - 生成每道题的评分明细
   - 计算总分和各项得分

4. **结果处理**：
   - 自动汇总考核成绩
   - 成绩数据自动归档
   - 同步推送结果至部门主管及人事
   - 支持部门主管在线确认最终结果

**输出**：
- 考生个人成绩单
- 评分明细（每题得分）
- 考核结果自动推送通知
- 成绩归档记录

#### 3.1.5 简历库管理

**功能描述**：

管理企业简历库，支持简历导入、检索、分类、标签化管理。

**输入**：
- 简历文件（仅支持 PDF、DOC、DOCX 格式）
- 岗位标签
- 匹配度标签

**处理规则**：

1. **自动导入**：
   - 筛选后的合格简历自动导入简历库
   - 支持手动批量导入简历
   - AI 自动解析简历内容，提取关键字段

2. **智能管理**（第三期）：
   - AI 识别重复简历并标记
   - 简历信息更新提醒
   - 简历人才标签智能画像
   - 支持按岗位、技能、学历等条件检索

**输出**：
- 简历库列表
- 简历详情页面
- 检索结果
- 重复简历提醒

### 3.2 入职管理

#### 3.2.1 入职作业

**功能描述**：

新员工扫码登录系统，完成实名认证、资料上传、协议签署等入职手续。

**输入**：
- 新员工二维码（唯一身份标识）
- 身份证正反面照片
- 学历证书照片
- 其他所需资料（如离职证明、体检报告等）

**处理规则**：

1. **扫码登录与实名认证**：
   - 新员工扫描入职二维码登录系统
   - 系统自动进行实名认证（比对身份证信息）
   - 法务要求的实名认证环节自动完成

2. **资料上传**：
   - 员工自行上传人事相关资料
   - 支持附件上传功能
   - 必填资料清单：学历证、身份证、离职证明、体检报告等
   - 支持格式：仅支持 PDF、JPG、PNG 三种格式，单文件不超过 10MB

3. **证件智能识别**：
   - AIOCR 识别上传的证件信息
   - 自动提取关键字段（姓名、身份证号、学历、专业等）
   - 校验信息完整性
   - 信息不完整时自动提示补充
   - 证件影像按类型分类存入档案库

4. **电子协议签署**：
   - 所有需签写的附加协议导入系统
   - 员工在线阅读协议内容
   - 支持手工电子签名确认
   - 系统记录签名时间、IP 地址、设备信息、用户账号
   - 电子签名符合《中华人民共和国电子签名法》第十三条规定的可靠电子签名要求（签名制作数据为电子签名人专有、签署时签名制作数据仅由电子签名人控制、签署后对电子签名的任何改动能够被发现、签署后对数据电文内容和形式的任何改动能够被发现），具备《电子签名法》第十四条规定的与手写签名或盖章具有同等法律效力

5. **人事基本资料自动生成**：
   - 系统整合证件信息、实名认证、电子协议、基本信息
   - AI 自动拼接生成标准人事基础档案
   - 无需人工录入

6. **人事打印**：
   - 人事可以随需自行打印相关档案
   - 支持单份打印和批量打印

**输出**：
- 完整的人事基础档案
- 电子签名协议存档
- 证件影像档案
- 入职资料清单确认单

#### 3.2.2 人脸资料录入

**功能描述**：

新员工入职时进行人脸采集，AI 完成人脸比对、编号绑定工号，自动录入人脸档案库。

**输入**：
- 新员工人脸照片（实时采集或上传）
- 员工工号
- 身份证信息

**处理规则**：

#### 3.8.2 薪资自动核算

**功能描述**：

依托薪资标准、考勤数据、补贴/扣款规则，AI 全自动计算月度薪资。

**输入**：
- 当月考勤数据
- 薪资标准
- 补贴/扣款规则
- 社保缴纳数据
- 公积金缴纳数据

**处理规则**：

1. **数据整合**：
   - 自动获取当月考勤数据
   - 自动获取薪资标准
   - 自动获取补贴/扣款规则
   - 自动获取社保/公积金数据

2. **薪资计算**：
   - AI 按以下公式计算月度薪资：
     - 应发工资 = 基本工资 + 考勤相关薪资 + 各类补贴
     - 考勤相关薪资 = 加班费 - 迟到扣款 - 早退扣款 - 缺勤扣款
     - 加班费 = 加班时长 × 小时工资 × 加班系数（工作日1.5倍、休息日2倍、法定假日3倍）
     - 迟到扣款 = 迟到次数 × 单次扣款金额（可配置，默认50元/次）
     - 个人应扣 = 社保个人部分 + 公积金个人部分 + 各类扣款
     - 应纳税所得额 = 应发工资 - 个人应扣 - 起征点（5000元）- 专项附加扣除
     - 个人所得税 = 按《中华人民共和国个人所得税法》规定的七级超额累进税率表计算（3%-45%）
     - 实发工资 = 应发工资 - 个人应扣 - 个人所得税
   - 薪资异常自动标记，异常定义如下：
     - 实发工资与上月波动超过 ±20%
     - 个人所得税为负值
     - 社保/公积金缴纳金额为 0 但员工状态为在职
     - 考勤数据缺失率超过 5%
     - 实发工资低于当地最低工资标准

3. **薪资台账生成**：
   - 生成薪资明细台账
   - 留存核算底稿档案
   - 支持薪资数据导出

**输出**：
- 月度薪资明细表
- 薪资核算底稿
- 薪资台账
- 异常薪资清单

## 4. 非功能需求

### 4.1 性能需求

#### 4.1.1 响应时间

| 操作 | 响应时间要求 |
|------|-------------|

| 薪资核算 | 全员核算 < 10 分钟 |
| 二维码生成 | < 1 秒 |
| AIOCR 识别 | 单张证件 < 3 秒 |
| 人脸比对 | < 2 秒 |

#### 4.1.2 并发能力

- 支持至少 100 人同时在线使用
- 支持大规模签到并发：培训签到场景支持不少于 200 人同时扫码签到，系统响应时间不超过 5 秒
- 薪资核算支持高并发数据处理

#### 4.1.3 数据处理能力

- 简历库支持存储至少 10 万份简历
- 支持日均处理 500 份简历筛选
- 支持月度全员薪资自动核算

### 4.2 安全性需求

#### 4.2.1 数据安全

- 员工个人信息（身份证、人脸等）加密存储
- 薪资数据严格权限控制
- 数据传输采用 HTTPS 加密
- 数据库定期自动备份
- 敏感操作记录审计日志，审计日志字段要求如下：
  - 操作时间（精确到秒）
  - 操作人账号和姓名
  - 操作人 IP 地址
  - 操作类型（新增/修改/删除/查看/导出/登录/登出）
  - 操作模块（招聘/入职/培训/考勤/薪资/绩效/外务/离职）
  - 操作对象 ID 和名称
  - 操作前数据快照（JSON 格式）
  - 操作后数据快照（JSON 格式）
  - 操作结果（成功/失败）
  - 操作耗时（毫秒）
  - 审计日志不可修改、不可删除，保留不少于 10 年

#### 4.2.2 身份认证

- 所有用户登录需身份认证
- 面试人员扫码验证登录
- 新员工实名认证
- 支持多因素认证（短信验证码），以下场景必须启用多因素认证：
  - 系统管理员首次登录
  - 人事专员访问薪资数据模块
  - 外务专员登录社保/公积金相关操作
  - 任何涉及员工敏感信息导出操作
  - 密码重置操作

#### 4.2.3 权限管理

- 基于角色的权限控制（RBAC）
- 不同角色访问不同功能模块
- 数据行级权限控制（如只能查看本部门员工数据）
- 操作权限分级管理

### 4.3 可用性需求

#### 4.3.1 系统可用性

- 系统正常运行时间 >= 99.5%
- 计划维护窗口不超过每月 4 小时

#### 4.3.2 易用性

- 界面简洁直观，操作简便
- 扫码签到等关键操作流程不超过 3 步（步骤计数从用户打开扫码界面开始计算：第1步打开扫码界面、第2步扫描二维码、第3步完成签到确认）
- 支持移动端和 PC 端访问
- 提供操作指引和帮助文档

### 4.4 可靠性需求

- 数据不丢失，关键操作有确认机制
- 系统异常时自动恢复
- 重要数据多重备份
- 薪资核算等关键操作支持校验和复核

### 4.5 可维护性需求

- 模块化设计，便于功能扩展
- 配置化规则管理（薪资规则、考勤规则等）
- 日志记录完整，便于问题排查
- 支持系统参数在线配置

### 4.6 可扩展性需求

- 支持招聘平台接口扩展
- 支持打卡设备接口扩展
- 支持外部系统对接（如 ERP、财务系统）
- 支持自定义表单和流程
- 支持 AI 模型升级和替换

### 4.7 系统监控与告警

#### 4.7.1 监控指标

系统需监控以下指标并支持可视化展示：
- CPU 使用率（告警阈值：持续 5 分钟超过 85%）
- 内存使用率（告警阈值：持续 5 分钟超过 90%）
- 磁盘使用率（告警阈值：超过 80%）
- 数据库连接池使用率（告警阈值：超过 80%）
- API 接口响应时间（告警阈值：P95 超过 5 秒）
- 系统活跃用户数
- AI Agent 任务执行成功率（告警阈值：低于 95%）
- 简历筛选队列积压数量（告警阈值：超过 500 份）
- 薪资核算任务执行状态

#### 4.7.2 告警方式

- 系统异常通过短信和邮件通知系统管理员
- 告警级别分为：紧急（5 分钟内通知）、重要（30 分钟内通知）、一般（下次工作时段通知）
- 支持告警自动升级：紧急告警 15 分钟未处理自动升级通知部门主管

### 4.8 数据导入导出规范

#### 4.8.1 简历批量导入

- 迁移方式：通过 Excel 批量导入或数据库直连迁移
- 迁移验证：迁移后执行数据完整性校验（记录数核对、关键字段非空校验、关联关系校验）
- 迁移回退：迁移前完整备份原系统数据，迁移失败时可恢复至迁移前状态
- 迁移时间窗口：系统切换期间执行，预计迁移时间不超过 4 小时

## 7. 部署架构

### 7.1 部署模式

本系统采用云部署模式，支持以下部署方式：

| 部署模式 | 适用场景 |
|---------|---------|
| 公有云部署 | 推荐模式，部署于阿里云/腾讯云等公有云平台 |
| 私有云部署 | 对数据安全有极高要求的场景，部署于企业内部数据中心 |
| 混合部署 | 核心数据部署于私有环境，AI 推理服务调用云端 API |

### 7.2 系统架构组件

| 组件 | 说明 |
|------|------|
| Web 应用服务器 | Nginx + 应用服务（建议不少于 2 台，负载均衡） |
| 数据库服务器 | MySQL/PostgreSQL（主从复制架构） |
| 缓存服务器 | Redis（集群模式） |
| 文件存储 | 对象存储（如阿里云 OSS）或 NAS |
| AI 推理服务 | 可部署于云端 GPU 实例或独立 AI 服务器 |
| 消息队列 | RabbitMQ/Kafka（用于 Agent 间通信） |

### 7.3 系统回退与降级方案

#### 7.3.1 系统回退

- 版本回退：每个版本发布前保留上一版本完整镜像，新版本出现问题时可在 30 分钟内回退至上一版本
- 数据回退：每次版本升级前自动备份数据库，回退时同步恢复数据至升级前状态

#### 7.3.2 功能降级

当部分 AI 服务不可用时，系统支持以下降级策略：
- AI 简历筛选不可用：切换至关键词匹配模式（基于学历、经验、技能等硬性条件的规则匹配）
- AIOCR 识别不可用：切换至手动录入模式
- 人脸比对不可用：切换至身份证号码+手机号验证模式
- AI 薪资核算不可用：切换至基于固定公式的规则计算模式
- 降级模式不影响系统核心功能可用性，仅降低自动化程度

## 附录 A：AI 原生系统架构设计要点

### A.1 AI Agent 编排

本系统采用多 AI Agent 协作架构。各 Agent 为用户角色提供自动化能力支撑，不替代用户角色的人工审批和决策职责：

1. **招聘 Agent**：为人事专员提供简历抓取、筛选、匹配、评分的自动化能力；待定简历仍需人事专员人工确认
2. **入职 Agent**：为新员工和人事专员提供入职资料收集、证件识别、档案生成的自动化能力；异常情况由人事专员处理
3. **培训 Agent**：为培训管理人员提供培训签到、考试评分、资料归集的自动化能力；主观题评分由人工完成
4. **考勤 Agent**：为人事专员提供考勤统计、异常识别的自动化能力
5. **薪资 Agent**：为人事专员提供薪资核算、工资条生成的自动化能力；异常薪资由人事专员复核
6. **绩效 Agent**：为员工和部门主管提供绩效考核数据收集和汇总的自动化能力；考核结果确认由部门主管完成
7. **外务 Agent**：为外务专员提供工伤资料归集、公积金信息预填的自动化能力；工伤理赔最终确认、公积金网站操作由外务专员人工完成

各 Agent 之间通过消息队列或事件总线通信，实现端到端业务流程自动化。

### A.2 AI 能力集成

| AI 能力 | 应用场景 |
|---------|---------|
| NLP 语义理解 | 简历解析、岗位要求匹配、心得报告分析 |
| AIOCR | 证件识别、纸质回执识别 |
| 计算机视觉 | 人脸采集与比对、签名验证 |
| 智能评分 | 客观题自动阅卷 |
| 智能组卷 | 基于题库的自动试题抽取 |
| 视频生成 | 教材转视频 |
| 智能提醒 | 证书到期提醒、复训提醒 |
| 数据汇总分析 | 绩效汇总、培训评估报告生成 |

### A.3 人机协作模式

| 场景 | AI 处理 | 人工处理 |
|------|---------|----------|
| 简历筛选 | 自动匹配评分、分类归档 | 待定简历（合格线±10分）人事专员人工确认 |
| 面试评分 | 客观题自动评分 | 主观题（简答、论述）人工评分 |
| 入职办理 | 证件识别、档案生成 | 异常处理由人事专员完成 |
| 薪资核算 | 自动计算 | 异常薪资（波动超过±20%等）人事专员复核 |
| 离职申请 | 表单自动生成 | 离职审批由部门主管完成 |
| 工伤理赔 | 资料归集、完整性校验 | 最终确认提交由外务专员完成 |
| 公积金管理 | 信息预填、补缴计算 | 网站登录和操作由外务专员人工完成 |
