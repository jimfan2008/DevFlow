## 1. 系统总体架构

### 1.1 架构愿景

GBM AI Agent HR 系统是一套**彻底的 AI 原生系统**，以 AI Agent 为业务执行主体，人类用户仅承担战略性审核与争议仲裁职责。系统架构围绕"零操作性原则"构建，所有可操作性事务由 AI Agent 自主完成端到端闭环。

### 1.3 架构设计原则

1. **Agent-first 架构** —— 所有功能以 AI Agent 为核心设计和交付，不存在先有人工操作再自动化的路径
2. **端到端自主闭环** —— 每个业务流程从触发到归档由 Agent 链自动串联完成
3. **零操作性原则** —— 凡是可以由系统自动完成的步骤，绝不给人工操作留口子
4. **松耦合微服务** —— 各模块 Agent 可独立部署、独立升级、独立扩缩容
5. **配置驱动** —— 薪资规则、考勤规则、筛选权重等均以配置驱动，Agent 读取参数自动计算
6. **透明可追溯** —— 每个 Agent 决策都有完整推理链记录，支持全链路追踪
7. **安全护栏** —— Agent 执行关键操作前设有自动阻断规则

## 2. 分层架构详解

### 2.1 展示层 (Presentation Layer)

展示层负责用户交互界面和通知渠道，支持多端访问。

| 组件 | 技术选型 | 说明 |
|------|---------|------|
| Web 端 | React 18 + TypeScript + Ant Design 5 | 人事专员、部门主管、系统管理员操作界面 |
| 移动端 | React Native / Taro (跨平台) | 员工自助查询、扫码签到 |
| 扫码入口 | H5 页面 (QR Code 解析) | 考试签到、培训签到扫码入口 |
| 邮件通知 | SMTP / Amazon SES | 系统通知邮件推送 |
| 短信通知 | 阿里云短信 / 腾讯云短信 API | 验证码、提醒短信推送 |
| 反向代理 | Nginx | 静态资源服务、反向代理、负载均衡 |

### 2.2 应用服务层 (Application Layer)

应用服务层提供通用基础服务，被各业务 Agent 共享调用。

| 服务 | 技术选型 | 职责 |
|------|---------|------|
| 用户认证服务 | Spring Security + JWT | 身份认证、令牌管理、MFA 二因子认证 |
| 权限管理服务 | RBAC 引擎 (自研) | 角色权限管理、数据行级隔离 |
| 通知中心 | 自研消息推送服务 | 统一消息推送 (邮件/短信/APP 推送) |
| 文件服务 | Spring + MinIO SDK | 文件上传、下载、预览、OCR 预处理 |
| 审计日志服务 | 自研审计引擎 | 不可篡改审计日志记录 (≥10 年保藏) |
| 报表导出服务 | Apache POI + iText | Excel/PDF 报表导出 |
| 配置管理服务 | Nacos / Apollo | 薪资规则、考勤规则、筛选权重等配置热更新 |
| 工作流引擎 | Camunda 7 / Flowable | BPMN 风格流程编排引擎 |

### 2.3 Agent 编排调度层 (Orchestration Layer)

Agent 编排层是系统的"大脑"，负责任务分解、Agent 调度和结果汇聚。

| 组件 | 技术选型 | 职责 |
|------|---------|------|
| 流程定义器 | 自研 DSL + Camunda BPMN | 定义端到端业务流程 (Pipeline/Fan-Out/Decision/Feedback Loop) |
| 任务分解器 | 自研任务拆分引擎 | 将业务流程拆解为子任务，分配给合适的 Agent |
| 路由调度器 | 自研路由引擎 + RabbitMQ/Kafka | 消息路由、Agent 调度、优先级管理 |
| 状态管理器 | 自研状态机 + Redis | 流程状态持久化、断点恢复、事务一致性 |
| 事件总线 | RabbitMQ (内部通信) / Kafka (高吞吐) | Agent 间消息传递、事件驱动 |

**编排模式支持：**

1. **Pipeline 流水线** —— 顺序执行 (如入职办理流程)
2. **Fan-Out/Fan-In 扇出扇入** —— 并行处理 (如薪资核算多源数据获取)
3. **Decision Tree 决策树** —— 条件分支 (如简历筛选区间分拣)
4. **Feedback Loop 反馈环** —— 结果反馈与纠偏 (如 OCR 失败重试)

### 2.4 AI Agent 群 (Agent Cluster)

共 20 个 AI Agent，按业务模块分组部署。

| 分组 | Agent 列表 | 技术栈 |
|------|----------|--------|
| 招聘管理 | 招聘渠道 Agent、简历匹配 Agent、组卷 Agent、阅卷 Agent | LLM + 规则引擎 + 题库服务 |
| 入职管理 | 入职引导 Agent、OCR Agent、人脸 Agent | LLM + PaddleOCR + Face++ |
| 培训管理 | 培训 Agent、教材转视频 Agent、审核资料 Agent | LLM + FFmpeg + 图像生成 |
| 考勤管理 | 考勤 Agent | 规则引擎 + 统计分析 |
| 薪资管理 | 薪资 Agent、工资条 Agent | 规则引擎 + 税法计算器 |
| 绩效管理 | 绩效 Agent | LLM + 统计分析 |
| 外务管理 | 外务 Agent、RPA Agent | Playwright + LLM |
| 离职管理 | 离职 Agent | LLM + 规则引擎 |
| 综合服务 | 证明 Agent、预算 Agent、分析 Agent | LLM + OCR + 规则引擎 |

### 2.5 AI 模型服务层 (AI Model Layer)

| 模型类型 | 选型 | 部署方式 | 用途 |
|---------|------|---------|------|
| LLM | GPT-4 / Claude / Qwen | 云端 API + 本地 vLLM | 语义理解、文本生成、推理决策 |
| OCR | PaddleOCR | 本地部署 | 证件识别、票据识别 |
| 人脸识别 | Face++ / ArcFace | 本地部署 / API | 人脸采集、比对、活体检测 |
| Embedding | bge-m3 / text-embedding-3 | 本地部署 | 简历向量化、语义搜索 |
| ASR | Whisper (本地化) | 本地部署 | 语音转写 |
| 视频生成 | FFmpeg + 图像生成 API | 混合部署 | 培训教材转视频 |

### 2.6 数据基础设施层 (Data Infrastructure)

| 组件 | 技术选型 | 用途 |
|------|---------|------|
| 关系数据库 | MySQL 8.x (主从模式) | 结构化数据持久化 (用户、薪资、考勤等) |
| 缓存 | Redis Cluster | 会话、Agent 锁、热点数据 |
| 对象存储 | MinIO | 简历文件、证件影像、培训视频等 |
| 消息队列 | RabbitMQ (Agent 通信) + Kafka (高吞吐) | Agent 间消息传递、事件驱动 |
| 搜索引擎 | Elasticsearch | 简历搜索、日志检索 |
| 向量数据库 | Milvus / Chroma (可选) | 简历向量化检索、知识嵌入 |

## 3. 模块划分

### 3.1 招聘管理模块

**包含 Agent：** 招聘渠道 Agent、简历匹配 Agent、组卷 Agent、阅卷 Agent

**核心功能：**
- 多渠道招聘信息自动发布
- 定时简历抓取 (每 15 分钟) 与去重
- 多维度匹配评分 (6 维度加权)
- 智能组卷与二维码绑定
- 客观题自动阅卷 + 主观题 AI 交叉评分
- 简历库管理与人才画像

**降级模式：** LLM 不可用时退化为关键词正则匹配模式

### 3.2 入职管理模块

**包含 Agent：** 入职引导 Agent、OCR Agent、人脸 Agent

**核心功能：**
- 扫码入职门户引导
- 证件 OCR 识别与校验
- 实名认证比对
- 电子协议签署
- 人脸采集与门禁系统对接
- 人事档案自动生成

**降级模式：** OCR 不可用时转为人工录入；人脸不可用时降级为"身份证+手机验证码"模式

### 3.3 培训管理模块

**包含 Agent：** 培训 Agent、教材转视频 Agent、审核资料 Agent

**核心功能：**
- 培训计划自动生成
- 扫码签到与统计
- 自动组卷与阅卷
- 结业证书/上岗证自动生成
- 教材文档转视频课程
- 体系审核资料一键归集

### 3.4 考勤管理模块

**包含 Agent：** 考勤 Agent

**核心功能：**
- 多源打卡数据自动汇聚
- 班次对照与异常标记
- 出勤天数/迟到/早退/缺卡/旷工/加班核算
- 异常趋势分析
- 加班超限预警 (36h/月上限)

### 3.5 薪资管理模块

**包含 Agent：** 薪资 Agent、工资条 Agent

**核心功能：**
- 薪资档案与规则维护
- 全自动月度薪资核算 (含加班费、社保、个税计算)
- 异常检测 (波动>±20%、个税负数等)
- 电子工资条批量发放与追踪
- 薪资数据导出 (限人事主管与系统管理员)

**安全护栏：** 金额变动需人事专员审核批准；操作二次校验

### 3.6 绩效管理模块

**包含 Agent：** 绩效 Agent

**核心功能：**
- 员工绩效自评收集
- 管理人员绩效互评/评议
- 绩效汇总与分布分析
- 部门对比与趋势报告

### 3.7 外务管理模块

**包含 Agent：** 外务 Agent、RPA Agent

**核心功能：**
- 工伤事故全流程处理 (说明生成→材料收集→RPA 申报→理赔跟踪)
- 公积金 RPA 自动操作 (开户/封存/补缴)
- 可扩展的政府申报 Agent 模板
- RPA 操作截图凭证自动归档

**降级模式：** RPA 被拦截时转外务专员手动操作，Agent 预填数据减轻负担

### 3.8 离职管理模块

**包含 Agent：** 离职 Agent

**核心功能：**
- 离职申请审核与推送
- 标准化交接清单生成
- 多部门交接跟踪
- 离职证明自动签发
- 离职资料归档

### 3.9 综合服务模块

**包含 Agent：** 证明 Agent、预算 Agent、分析 Agent

**核心功能：**
- 人事证明自助签发 (在职/收入/离职证明)
- 费用单据 OCR 分类与汇总
- 发票真伪校验
- 经营分析报告自动生成

### 5.4 网络架构

| 层级 | 网络策略 |
|------|---------|
| 外部访问 | 通过 Nginx/HAProxy 负载均衡器，HTTPS (TLS 1.2+) |
| 内部通信 | K8s Service + CNI (Calico/Flannel)，Pod 间直接通信 |
| Agent 通信 | 通过 RabbitMQ/Kafka 消息队列，不直接 HTTP 调用 |
| 外部 API | 通过 API Gateway 统一出口，配置超时与熔断 |
| RPA 访问 | 独立网络命名空间，与政府网站通信需配置代理 |

### 5.5 降级架构

当部分组件不可用时，系统支持优雅降级：

| 失效场景 | 降级策略 | 架构图变化 |
|---------|---------|-----------|
| LLM 不可用 | 简历筛选→关键词正则匹配；文书生成→预置模板 | Agent 群中 LLM 依赖模块切换为规则引擎 |
| OCR 不可用 | 证件信息→人工录入 (降级例外) | OCR Agent 暂停，前端开放人工录入入口 |
| 人脸不可用 | 身份校验→"身份证+手机验证码" | 人脸 Agent 暂停，Auth Service 启用降级验证 |
| 编排层异常 | Agent 手动调度模式 | 编排层暂停，管理员控制台手动触发 Agent |
| RPA 被拦截 | 转外务专员手动操作 | RPA Agent 暂停，外务专员窗口接管 |
| DB 故障 | 自动切从库 (15 分钟内)；双主宕机→只读模式 | DB 层自动切换，前端查询可用 |

## 6. 安全架构

### 6.1 数据安全

| 安全措施 | 实现方式 |
|---------|---------|
| 敏感数据加密 | AES-256 加密存储 (身份证号、人脸特征、薪资数据) |
| 密钥管理 | 独立密钥保管库，定期轮换 |
| 传输加密 | TLS 1.2+ 强制 |
| 数据不出境 | 物理存储位置为中国境内数据中心 |
| 操作审计 | 不可篡改审计日志 (≥10 年保藏) |
| 二次校验 | 薪资等资金变动操作需二次确认 |

### 6.2 认证与授权

| 机制 | 实现 |
|------|------|
| 身份认证 | Spring Security + JWT |
| MFA 二因子 | 管理员首次登录、薪资数据访问、公积金/社保操作、大批量导出、密码重置 |
| RBAC 权限 | 基于角色的访问控制 |
| 数据行级隔离 | 部门主管仅查看本部门下属数据 |
| 临时授权 | 面试官凭二维码登录 (时效≤2 小时) |

### 6.3 Agent 安全护栏

| 护栏类型 | 实现机制 |
|---------|---------|
| 金额操作护栏 | Agent 修改金额前需人事专员审核批准 |
| 对外通讯护栏 | Agent 发送外部邮件前需预审确认 |
| 数据删除护栏 | Agent 仅能移动归档位，删除需二次审批 |
| 模型推理护栏 | 输出合理性阈值检查 (薪资≠0、评分∈[0,100]) |
| Prompt 注入防护 | 输入安全过滤，防范越狱攻击 |

| Agent 操作成功率 | < 95% | 自定义 Metrics |
| 简历筛选积压量 | > 500 份 | 自定义 Metrics |
| 薪资核算任务状态 | 超时或失败 | 自定义 Metrics |

### 7.2 告警机制

| 级别 | 响应时间 | 通知方式 | 升级策略 |
|------|---------|---------|---------|

| 重要 | 30 分钟内 | 邮件 + SMS | 无 |
| 一般 | 下一工作日 | 邮件通知 | 无 |

### 7.3 日志体系
