# Aeternova SRS V1

## 1. 引言

本文档定义 Aeternova 项目的软件需求规格。

## 2. 功能需求

### 2.1 告警通知系统

- **FR-001**: 严重级别告警应通知系统管理员和项目负责人
- **FR-002**: 非严重级别告警仅通知项目负责人
- **FR-003**: 告警通知应在 ≤30 秒内送达
- **FR-004**: 通知应包含告警消息内容
- **FR-005**: 通知记录应可追溯（sent_at 时间戳）

### 2.2 主持人权限系统

- **FR-006**: 主持人可禁言普通成员
- **FR-007**: 主持人可发布公告
- **FR-008**: 主持人可管理会议
- **FR-009**: 主持人不可移除成员
- **FR-010**: 主持人不可解散群组
- **FR-011**: 主持人不可操作其他主持人

## 3. 非功能需求

- **NFR-001**: 告警处理延迟不超过 30 秒（P99）
- **NFR-002**: 系统支持高并发通知路由
- **NFR-003**: 所有接口需提供权限校验

## 4. 约束

- 运行环境：Python 3.11+, FastAPI
- 测试框架：pytest + pytest-asyncio
